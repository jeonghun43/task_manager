# 작업 관리 칸반 — 계층형 시각 태스크 매니저

큰 과업(목표)을 작은 과업(실행 단위)으로 쪼개서 관리하고,
같은 데이터를 **과업별 / 상태별 / 마감기한별 / 캘린더** 네 가지 시선으로 보는 도구입니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

http://localhost:3000 접속. 첫 실행 시 구조를 보여주는 샘플 데이터가 들어갑니다
(⋯ 메뉴 → `전부 비우기` 로 지울 수 있어요).

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run start` | 빌드 결과 실행 |
| `npm run typecheck` | 타입 검사 |
| `npm run lint` | ESLint |

## 핵심 개념

- **큰 과업** — 달성하려는 목표. 그 자체로는 착수할 수 없다. 상태·우선순위·마감일·색상을 가진다.
- **할 일** — 실제로 체크할 수 있는 실행 단위. 반드시 하나의 큰 과업에 속한다.
- **우선순위 상속** — 할 일은 기본적으로 소속 큰 과업의 우선순위를 따라간다.
  큰 과업의 우선순위를 바꾸면 상속 중인 할 일도 함께 바뀐다.
  개별 지정한 할 일은 영향받지 않으며, 언제든 상속으로 되돌릴 수 있다.
- **큰 과업의 상태는 수동 지정** — 하위 완료율에 따라 자동으로 바뀌지 않는다.
  대신 진행률(`3/7 · 43%`)이 헤더에 표시된다.

## 네 가지 뷰

| 뷰 | 무엇을 보는가 | 정렬 |
|---|---|---|
| **오늘** (기본) | 마감 지남 / 오늘 할 일 / 오늘 끝낸 것 | 우선순위 순 |
| 과업별 | 큰 과업 = 컬럼, 할 일 = 카드 | **마감일 순**(기본) ↔ 직접 정한 순서 |
| 상태 | To-Do / 진행 중 / 완료 칸반 | 컬럼 안은 마감일 → 우선순위 |
| 마감기한 | 지남 / 오늘 / 내일 / 이번 주 / 이후 / 기한 없음 | 마감일 → **같은 날짜면 우선순위 높은 것이 위** |
| 캘린더 | 월간 그리드 + 미배치 트레이 + **역산 플래너** | 날짜 안에서 우선순위 |

어느 뷰에서든 카드에는 소속 큰 과업이 색상 배지로 붙어 있어 출처를 잃지 않습니다.

## 역산 플래너 — 목표에서 거꾸로 오늘까지

최종 목표의 마감일을 앵커로 두고, 하위 할 일을 남은 날에 나눠 놓아
**오늘 해야 할 것**을 뽑아내는 흐름입니다. 캘린더 뷰에서 씁니다.

1. 캘린더 뷰 상단에서 계획할 **큰 과업을 하나 고릅니다.** `마감까지 12일` 이 표시되고 남은 구간이 옅게 칠해집니다.
2. 오른쪽 **아직 날짜 없음** 트레이에 하위 할 일이 순서대로 모입니다.
3. **`⤺ 역산 배치`** 를 누르면 마감일에서 거꾸로, 순서를 지켜 날짜가 배분됩니다.
   첫 항목은 오늘, 마지막 항목은 마감일에 놓입니다. **주말도 작업일로 씁니다.**
4. 결과는 **미리보기**입니다(점선 표시). 마음에 안 드는 항목은 다른 날로 끌어다 놓으세요.
   트레이로 되돌리면 날짜가 지워집니다.
5. **확정**을 누르면 저장됩니다. 이제 헤더의 `오늘 N` 이 오늘 해야 할 것입니다.

확정하지 않은 채 다른 화면(과업별·상태·마감기한)으로 옮기려 하면
`저장하고 이동` / `저장 안 하고 이동` / `취소` 를 묻습니다.
미리보기는 확정 전 값이라 저장되지 않으므로, 새로고침하면 사라집니다.

자동 배치는 정답이 아니라 **출발점 제안**입니다. 항목별 실제 소요 시간은 제각각이므로
확정 전에 드래그로 조정하는 단계를 반드시 거치도록 만들어져 있습니다.

## 조작

- **할 일 추가**: 컬럼 위쪽 `＋ 할 일 추가` → 제목 입력 → Enter (입력창이 유지되어 연속 입력).
  새 할 일은 **맨 위에** 쌓이므로, 연속으로 적으면 먼저 적은 것이 아래로 내려갑니다.
- **완료**: 카드 왼쪽 체크박스
- **되돌리기**: 삭제·드래그로 인한 변경은 확인 없이 즉시 실행되고, 하단 토스트의 `실행 취소`로
  10초 안에 되돌릴 수 있습니다. 큰 과업 삭제와 `전부 비우기`만 확인을 받습니다.
- **마감일**: 카드의 `📅` 칩을 눌러 그 자리에서 변경 (오늘 / 내일 / 모레 / 다음 주 / 직접 입력 / 지우기)
- **이동/정렬**: 카드 드래그. 모바일은 길게 눌러 시작합니다.
  드래그로 가능한 모든 동작은 카드의 `⋮` 메뉴로도 할 수 있습니다.
- **과업별 뷰 정렬**: 좌상단 `⇅ 마감일 순` 버튼으로 전환. 마감일 순일 때는 정렬이 순서를 정하므로
  같은 컬럼 안에서의 재배치 드래그는 받지 않습니다(다른 과업으로 옮기는 건 그대로 됩니다).
- **필터**: 상단 `⚟` — 큰 과업 / 우선순위 / 완료 숨기기. 걸린 필터는 상단에 칩으로 표시됩니다.
- **데이터**: 상단 `⋯` — JSON 내보내기·가져오기, 샘플 불러오기, 전부 비우기, 테마 전환

## 데이터 저장

현재는 **브라우저 localStorage** 에 저장됩니다. 서버도 로그인도 없고, 오프라인에서 동작합니다.
기기 간에는 동기화되지 않으므로 옮길 때는 JSON 내보내기/가져오기를 쓰세요.

저장은 전부 `StorageAdapter` 인터페이스를 거칩니다.

```
src/lib/storage/adapter.ts   인터페이스
src/lib/storage/local.ts     localStorage 구현
```

UI 컴포넌트는 `localStorage` 를 직접 만지지 않습니다.
`useAppStore` 만이 어댑터를 호출하므로, 나중에 서버를 붙일 때는
`SupabaseAdapter` 같은 구현을 하나 만들어 `setStorageAdapter()` 로 갈아끼우면 됩니다.
화면 코드는 바꿀 필요가 없습니다.

## 구조

```
src/
  app/                 Next.js App Router (레이아웃 · 테마 부트스트랩)
  lib/
    types.ts           도메인 모델
    derive.ts          우선순위 상속 · 진행률 · 정렬 (파생 계산의 단일 지점)
    schedule.ts        역산 배치 알고리즘 (순수 함수)
    date.ts            "YYYY-MM-DD" 로컬 날짜 유틸
    storage/           영속화 경계
  store/
    useAppStore.ts     도메인 데이터 + 액션
    useUiStore.ts      뷰 · 필터 · 정렬 · 테마
    usePlanStore.ts    역산 배치 미리보기 (확정 전 값이라 영속화하지 않음)
  components/
    views/             4개 뷰
    ui/                Modal · Badge · Checkbox · Menu · Field
```

### 날짜를 다루는 규칙

마감일은 `"2025-05-23"` 형식의 **로컬 날짜 문자열**로만 저장합니다.
`Date.toISOString()` 을 마감일에 쓰면 UTC 변환으로 하루가 밀리므로 사용하지 않습니다.
